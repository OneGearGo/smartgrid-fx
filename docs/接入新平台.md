# 接入新外汇平台指南

本平台（fx-grid-bot）预留了 **5 个外汇平台接入位**：当前 5 个品种槽位全部使用 `mt5`
（共享一个 MT5 终端登入），但每个槽位的 `PLATFORM` 字段可以独立切换为其他平台。
本文档说明如何实现并接入第 2~5 个外汇平台（OANDA / FXCM / IC Markets / 盈透等）。

## 一、设计原则

- **网格引擎不感知平台**：`src/bot.js`（GridBot）只依赖统一适配器接口，换平台不需要改引擎；
- **每个平台 = 一个目录**：`src/exchange/<platform>/` 内含工厂 + paper/live 适配器；
- **paper 与 live 分离**：paper = 真实行情 + 本地模拟撮合（绝不发真实订单）；
  live = 真实行情 + 真实订单；
- **共享桥模式**（MT5 的做法）：多个槽位共用同一个平台连接（单终端登入）。

## 二、接口契约

完整契约见 [src/exchange/platforms/README.md](../src/exchange/platforms/README.md)。
核心要求（实现一个平台适配器必须提供）：

| 类别 | 成员 |
| --- | --- |
| 属性 | `mode` / `dataSource` / `network` / `feeRate` / `balance` / `equity` / `realizedPnl` / `lastOkAt` |
| 行情 | `init()` / `reconnect()` / `getMarkets()` / `getCandles()` / `getPrice()` / `setLeverage()` |
| 订单 | `placeLimitOrder()` / `cancelOrder()` / `cancelAll()` / `fetchOpenOrders()` / `adoptOrder()` |
| 持仓 | `getPosition()` / `closePosition()` |
| 生命周期 | `start()` / `stop()` / `forgetOrders()` |
| 事件 | `'fill'` / `'price'` / `'error'` |

> `'error'` 事件必须始终有监听器，否则 Node 进程会因未捕获 error 事件崩溃。
> `cancelOrder` 失败必须 throw（bot 依赖它做撤单安全确认）。

## 三、接入步骤（以 OANDA 为例）

### 1. 建目录与凭据配置

```
src/exchange/oanda/
├─ index.js     # createExchange(slotCfg, platformCfg, magic) 工厂
├─ oanda.js     # live 适配器（真实订单）
├─ paper.js     # paper 适配器（真实行情 + 本地模拟撮合）
└─ api.js       # OANDA REST 客户端（v20 API）
```

`.env` 增加（示例）：

```ini
XAU_PLATFORM=oanda
OANDA_API_KEY=xxx
OANDA_ACCOUNT_ID=xxx
OANDA_ENV=live        # live | practice（模拟账户）
```

### 2. 实现适配器

参考 `src/exchange/mt5/` 的现有实现：

- **行情**：OANDA v20 `/instruments/{instrument}/candles` 拉 K线，`/prices` 拉实时价；
- **订单**：`POST /accounts/{id}/orders` 挂限价单（`type=LIMIT`），`DELETE .../pendingOrders/{id}` 撤单；
- **成交检测**：OANDA 有交易流（transactions stream）可推送成交事件，或用轮询 diff（
  参考 `src/exchange/mt5/mt5.js` 的 `_diffOrders`）；
- **paper 撮合**：本地维护挂单簿，用真实价格路径判穿越成交，含手续费（参考 `mt5/paper.js`）。

### 3. 注册工厂

`src/server.js` 目前直接调用 `createExchange(slotCfg, mt5Cfg, magic)`。接入多平台后
改为按平台分发：

```js
import { createExchange as createMt5 } from './exchange/mt5/index.js';
import { createExchange as createOanda } from './exchange/oanda/index.js';

const PLATFORM_FACTORIES = {
  mt5:   (slotCfg, pCfg, magic) => createMt5(slotCfg, pCfg.mt5, magic),
  oanda: (slotCfg, pCfg, magic) => createOanda(slotCfg, pCfg.oanda, magic),
};

function createExchange(slotCfg, pCfg, magic) {
  const factory = PLATFORM_FACTORIES[slotCfg.platform] || PLATFORM_FACTORIES.mt5;
  return factory(slotCfg, pCfg, magic);
}
```

各平台共享/独立的连接管理（如 MT5 的 `getSharedBridge`）在各自工厂内部处理。

### 4. 配置槽位

`.env` 中把目标槽位切到新平台：

```ini
XAU_PLATFORM=oanda   # 只有 XAUUSD 走 OANDA，其余仍走 MT5
```

### 5. 验证

1. `npm run check:config` —— 确认配置可解析；
2. `npm test` —— 全部测试（含新适配器集成测试，建议仿照 `test/exchange-mt5.test.js` 写 FakeBridge 驱动的测试）；
3. paper 模式跑通全流程：启动网格 → 模拟成交 → 替换 → 停止/平仓 → 重启恢复；
4. 确认无误后，小资金切换 live，逐槽位验证。

## 四、常见平台速查

| 平台 | 行情/订单 API | 特点 |
| --- | --- | --- |
| OANDA | v20 REST（practice/live） | 免费模拟账户，REST 文档完善，限价单直接支持 |
| FXCM | REST + WebSocket | 需要 FXCM 账户与 access token |
| IC Markets | cTrader Open API / FIX | 需要 FIX 网关或 cTrader 桥 |
| Interactive Brokers | IBKR API（Python/Java） | 本地 TWS/IB Gateway 常驻，行情需订阅 |
| Pepperstone（当前） | MT5 终端（本仓库已实现） | 通过 `F:\MT5\terminal64.exe` + MetaTrader5 库 |

> 各平台条款、地域限制与费用不同，接入前自行确认资格并遵守规则。

## 五、安全提醒

- **paper 适配器严禁发送真实订单**——这是硬边界，测试时务必确认 `mode='paper'`；
- 密钥只从 `.env` 读取，禁止写日志/回显明文（前端 API 只回传掩码）；
- 实盘切换前：确认账户、杠杆、最小手数约束，先小资金验证；
- 新平台接入后，`closePosition` 等不可逆操作必须先在 paper 验证可用。
