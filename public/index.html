🤖 AI 接入配置

支持三种协议：openai（OpenAI / DeepSeek / Kimi / 通义 / 智谱 / OpenRouter / Ollama 等所有兼容服务，填对应接口地址即可）、anthropic（Claude）、gemini（Google）。
保存后立即生效、无需重启。留空的字段不会覆盖 .env 里已有的值（清空请直接编辑 .env）。

🛡 风控哨兵

按设定间隔自动巡检五品种状态（健康度/挂单同步/保证金/出区间/告警），发现问题推送通知。

尚无巡检结果
🚨 出区间 AI 建议
价格冲出网格区间时自动触发分析（平仓/回收/扩区间/维持），并推送通知；已配置的自动策略照常执行，AI 建议仅供复核。
📈 市况分析（当前适不适合跑网格）
综合 4小时/1小时/15分钟 三个周期的指标判断市况，给出区间/格数/间距建议。分析的是该所当前配置的市场。
📋 运行复盘日报
每天到点自动生成并推送；也可手动触发。
💬 对话操控

AI 基于五品种实时状态回答问题；涉及操作时它只能"提议"，你点确认后才会通过常规接口执行（保证金/杠杆等硬性风控不受 AI 影响）。

代理 / IP 配置

配置代理后，服务器重启才能生效（修改 .env 文件中对应字段）。
下方"测试连接"按钮会通过当前已配置的代理检测出口IP，无需重启。
全局代理优先级最高，会覆盖各交易所独立代理。

🌐 全局代理（GLOBAL_PROXY）

同时应用于所有五个交易所。留空则各交易所使用各自配置。

⬡ EURUSD 独立代理（EUR_PROXY）

仅用于 EURUSD 交易所。支持 HTTP(S) 和 SOCKS5（含用户名密码认证）。

⬡ GBPUSD 独立代理（GBP_PROXY）

仅用于 GBPUSD 交易所。

⬡ USDJPY 独立代理（JPY_PROXY）

仅用于 USDJPY 交易所。

⬡ XAUUSD 独立代理（XAU_PROXY）

仅用于 XAUUSD 交易所。

⬡ NAS100 独立代理（NAS_PROXY）

仅用于 Robinhood Chain Lighter 交易所。

🔍 代理连接测试

验证当前服务器的代理是否正常工作，并显示出口 IP。

⚠ 写入 .env 后需重启服务器才能让代理生效。
不同交易所配置不同代理时，因 Node.js 技术限制，实际生效代理为全局设置（GLOBAL_PROXY）。
如需严格隔离，建议分开部署各交易所版本。
